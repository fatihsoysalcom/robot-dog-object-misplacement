# Robot Dog Object Misplacement

This example simulates a simplified robot dog's autonomous "tidy up" behavior within a home environment. It demonstrates how a robot, programmed to organize objects, might unintentionally "misplace" or "steal" a personal item like a phone by moving it to an unexpected location, highlighting potential security or usability concerns with autonomous devices.

## Language

`python`

## How to Run

Save the code as `main.py` and run from your terminal:
`python main.py`
